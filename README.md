# Instruments

Each group's working space. Anything that shows how your instrument is developing goes here: code, photos, drawings, videos, wiring, notes.

- [group-1](group-1/)
- [group-2](group-2/)

## Adding things (all in the browser)

- **Files** (photos, videos, code): open your group's folder → **Add file → Upload files** → drag them in → **Commit changes**.
- **Writing:** open your group's folder → **Add file → Create new file**.

Files over 25 MB won't upload in the browser. Put big videos somewhere else and paste the link.
